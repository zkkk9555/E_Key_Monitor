# 中文入口与说明书实施计划

> 历史方案：本文件记录的 BAT 中文入口方案已被 `2026-07-24-single-exe-portable-launch-design.md` 取代；保留此文件作为历史记录，不作为当前便携包入口说明。

## 目标

让不熟悉脚本的用户可以从资源管理器中看懂并使用项目入口，同时保持现有启动逻辑、监控功能和安全边界不变。

## 实施范围

1. 保留现有英文 `.bat`、`.ps1` 文件作为内部兼容脚本，不重命名、不删除。
2. 增加中文文件名的双击入口；入口内容保持 ASCII，只调用同目录的现有 PowerShell 脚本。
3. 将用户提供的游戏目录 `E:\Youxi\网吧极速版\program` 写入根目录默认配置，并由现有构建流程复制到运行目录。
4. 让桌面快捷方式生成脚本直接指向中文入口，避免用户看到英文脚本名。
5. 新增中文使用说明书，解释每个入口、适用场景、配置位置、状态颜色、故障排查和已知限制。

## 不在范围内

- 不修改 C# 源代码、输入监听逻辑、绘制逻辑或游戏联动逻辑。
- 不直接启动或修改 `NarakaBladepoint.exe`。
- 不读取 `.env`、密钥、密码、证书等敏感文件。
- 不自动运行游戏或修改桌面现有快捷方式；用户可在完成后手动运行中文快捷方式生成入口。

## 验证

- 检查新增 BAT 内容为纯 ASCII，并且只调用同目录既有 PS1。
- 检查所有 PS1 仍为 UTF-8 with BOM，PowerShell 5.1 静态解析无错误。
- 检查根目录 JSON 可解析、游戏目录及两个游戏 EXE 存在。
- 执行 Release 构建、格式检查和无测试项目的测试命令（不启动游戏）。
- 复核变更列表，确认没有 C# 源代码、测试、依赖或锁文件改动。
